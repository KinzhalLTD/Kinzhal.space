KINZHAL NEST
Team sign-in

The games HQ of Kinzhal LTD Co.

Kinzhal Nest is a private, invite-only dashboard that Kinzhal LTD Co. uses to monitor and run its own mobile games. It brings each game's daily numbers into one place so the team can plan updates, marketing and releases.

It is an internal tool for the company's own team. It is not offered to the public and does not collect data from players.

Privacy policy

What it does

Game performance

Daily players, installs and retention for each game, read from Google Analytics for Firebase.

Revenue

Ad revenue from AdMob, plus sales and subscriptions from App Store Connect and RevenueCat.

Stability

Crash-free users from Firebase Crashlytics, so problems are fixed quickly.

Planning

Tasks, release plans, costs and reports for the team, exported as PDF.

How Google data is used

When the owner signs in with Google, Kinzhal Nest asks for read-only access to the company's own Google Analytics, AdMob, Firebase and BigQuery reports. The data is used only to show aggregated game metrics to invited team members. It is never sold, shared or used for advertising. Keys and tokens are encrypted and stored in the company's own Google Cloud project. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
